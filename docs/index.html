Privacy and security

What Joseon does with your data: nothing.

  • No account, no analytics, no telemetry.
  • No recording. Audio stays in memory, on your computer.
  • One network request: the release list on GitHub, to offer updates. Switch it off in Settings.
  • Microphone only when you start a headphone measurement.
  • Open source under the GPLv3. Checked against the source on 2026-10-13.

macOS
  1. Open the dmg, drag Joseon to Applications.
  2. First start: System Settings → Privacy & Security → Open Anyway.
  3. Allow "System Audio Recording". Play music.
macOS 14.4 or later · Apple silicon
Windows
  1. Unzip anywhere. Start Joseon.exe.
  2. First start: More info → Run anyway.
  3. Play music or a game.
Windows 10 or 11, 64-bit · Direct3D 12
